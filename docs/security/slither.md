# Slither triage

Command (from `contracts/`): `slither .` with `slither.config.json` (production code only; tests, scripts and libraries excluded). CI runs the same and fails on any High finding.

**Result (Slither 0.11, 2026-09-28): 0 High.** Every remaining Medium and Low finding is listed below with the reason it stays.

## Fixed after the first run

| Finding                                                                                                | Fix                                                                                           |
| ------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------- |
| `divide-before-multiply` in `FeeManager.computeFee` (agent share computed from an already-rounded fee) | Single `net × perfFee × agentShare / BPS²` division; the agent share can never exceed the fee |
| `divide-before-multiply` in `MandateGuard.check` (yield test)                                          | Compares `fairValue × premiumBps` with `collateral × minYieldBps` without dividing            |
| `reentrancy-no-eth` in `EpochManager.proposeSeries`                                                    | Series state is written before calling the agent registry (checks-effects-interactions)       |
| `uninitialized-local` (3)                                                                              | Explicit zero initialisation                                                                  |
| `shadowing-local` in `IStockOracle.status`                                                             | Return value renamed                                                                          |

## Accepted

| Finding                                          | Where                                                                                            | Why it is safe                                                                                                                                                                                                                                                                                                           |
| ------------------------------------------------ | ------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `divide-before-multiply` (8)                     | `NyseTime` (civil-date algorithms), `BlackScholesLib` (`_d1`, `expNeg`)                          | The calendar uses Hinnant's integer algorithms, where truncating division is the algorithm (validated against Python `zoneinfo` for every day 2026–2030). The pricer mirrors the Rust Stylus pricer operation for operation so the two agree exactly; accuracy vs closed-form Black-Scholes is tested to < 1e-9 of spot. |
| `incorrect-equality` (2)                         | `EpochManager._evaluate` (`tenor == 0`), `_quoteBuy` (`premium == 0`)                            | Comparisons on computed values, not on token balances an attacker can move.                                                                                                                                                                                                                                              |
| `reentrancy-no-eth` (1)                          | `EpochManager.settle`                                                                            | The only call before state writes is to the admin-configured `StockOracle` (trusted), and `settle` is `nonReentrant`. The oracle call must come first: the price decides the payout.                                                                                                                                     |
| `unused-return` (10)                             | Chainlink `latestRoundData` / `getRoundData` destructuring, `(price,) = oracle.latestPrice(...)` | Unneeded tuple fields are dropped on purpose; every used field is validated.                                                                                                                                                                                                                                             |
| `reentrancy-benign` (2), `reentrancy-events` (1) | `EpochManager` calls to the vault, registry and fee manager; `VaultFactory.createVault`          | All callees are Strike contracts; all entry points are `nonReentrant` where state could be affected.                                                                                                                                                                                                                     |
| `timestamp` (19)                                 | Epoch, expiry, staleness and unbonding checks; `UsdgDrip.drip`'s 24-hour cooldown (testnet)      | Options expire at timestamps by design. Sequencer timestamps drift by seconds; every window is minutes to days.                                                                                                                                                                                                          |
| `dead-code` (2)                                  | `StrikeVault._deposit` / `_withdraw`                                                             | False positive: they override OpenZeppelin's internal hooks, which `deposit`/`withdraw` call.                                                                                                                                                                                                                            |
| `low-level-calls` (2)                            | `SafeStockFeed._flag` / `_uint`                                                                  | Deliberate `staticcall`: testnet stock tokens do not implement `oraclePaused()`, so the read must not revert. Return data length is checked before decoding.                                                                                                                                                             |
| `unindexed-event-address` (6)                    | Admin events                                                                                     | Informational.                                                                                                                                                                                                                                                                                                           |
