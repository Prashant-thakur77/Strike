# Adversarial suite

Strike's tests grouped by attack. Each attack falls into one of four categories:

- **Cheat:** a participant (agent, buyer, curator, admin, oracle, a fake vault) tries to get more than the rules allow.
- **Replay:** a call that already took effect is sent again.
- **Double-spend:** the same claim (options, premium, shares, a slashed bond, a faucet drip, collateral) is used twice.
- **Offline:** a party the protocol depends on stops: the keeper and its feed, the agent, the token's oracle, the pricer, the L2 sequencer.

For each attack, the tables below give the defence in the contracts, the test that shows it, and the result. Each new test asserts the defence itself: the revert and its error, the slash, or the balances that did not move. A mutation check then confirms that these tests fail when the defence is removed.

New tests are named `test_ADV_<CATEGORY>_<attack>`. The ones for v2 behaviour live in [`contracts/test/adversarial`](../../contracts/test/adversarial) on `main`; the contracts they run against are the v2 sources, which are byte-identical to the verified v2 deployment. Tests for behaviour only v3 has (signer consent, fee high-water mark, active-agent rule, `RiskLens`) are in [`contracts/test/adversarial`](https://github.com/Prashant-thakur77/Strike/tree/v3-contracts/contracts/test/adversarial) on the `v3-contracts` branch. Where an existing test already proves an attack, the row links that test rather than repeating it.

## Commands

From the repository root, with Foundry on `PATH`:

```bash
# main (v2 sources)
forge test --root contracts --match-path "test/adversarial/*" -vv                  # 30 passing
forge test --root contracts --no-match-path "test/{fork,differential,formal}/*"   # 515 passing, 7 skipped
forge fmt --root contracts --check
python3 scripts/adversarial-mutation.py                                            # 16 of 16 caught

# v3-contracts, for example in a worktree next to this checkout
git worktree add ../strike-v3 v3-contracts
forge test --root ../strike-v3/contracts --match-path "test/adversarial/*" -vv                  # 5 passing
forge test --root ../strike-v3/contracts --no-match-path "test/{fork,differential,formal}/*"   # 531 passing, 1 skipped
python3 scripts/adversarial-mutation.py ../strike-v3/contracts                                   # 7 of 7 caught
```

The mutation script copies `contracts/` to a scratch directory and injects one bug at a time into the copy. It then runs the test that should catch that bug and reports whether it failed. The repository's own files are never changed.

## Not defended in code

These attacks are not stopped by the contracts. They are trust assumptions or accepted limits, listed so nobody reads the tables above as covering them:

- **A compromised admin can choose the settlement price before it is recorded.** The admin can point a token at another feed (`StockOracle.setFeed`), swap the oracle (`EpochManager.setOracle`) or swap the pricer (`setPricer`). After expiry and before anyone records the price, that lets it pick the settlement price or the sale prices. Once a price is recorded it is final; `test_ADV_CHEAT_adminCannotSettleOffTheFirstRound` swaps the feed afterwards and the price does not move. Mitigations: `settle` is permissionless, the keeper ([`keeper.yml`](../../.github/workflows/keeper.yml), every 10 minutes) settles expired epochs on the first print after expiry, and the mainnet admin is meant to be a Safe multisig ([threat model](../threat-model.md) T17). The "cannot move user funds" in [audit-readiness.md](../audit-readiness.md) holds only for an honest admin.
- **A malformed first print after expiry ends in a refund.** If the first round after expiry is zero or negative, the series cannot settle. After `settlementGrace` the guardian cancels and buyers get their premium back instead of a payout (`test_ADV_CHEAT_nonPositiveSettlementPrintNeverPays`). The protocol fails closed here. MirrorFeed refuses an answer ≤ 0, so on testnets such a round cannot exist; on mainnet it would take Chainlink publishing a non-positive price.
- **A keeper that fabricates a testnet print.** On testnets, MirrorFeeds are filled by the keeper; the mirror audit (`scripts/verify-mirror.mjs`) checks every round against the mainnet round it copies. Mainnet reads Chainlink directly.
- **An agent that goes inactive after opening (v3).** It can keep a vault locked for at most `proposalTimeout` (one day); the curator can abort at once (`test_ADV_CHEAT_agentDeactivatesAfterOpening`). No funds are at risk.
- **The faucet gives one drip per address,** so many addresses get many drips. Testnet USDG has no value.
- **v2 accepts any `agentId` at vault creation** (a known issue, fixed in v3 by the active-agent rule). A curator can name someone else's agent; that agent is never forced to propose, and only the curator's own vault is affected.
