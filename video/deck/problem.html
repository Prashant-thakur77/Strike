Options on the chain today are order books and vaults run by people. No agent can run one without holding the money.

Sources: docs.robinhood.com/chain (ERC-8056 stock tokens); stonkhouse.fun (live on mainnet); github.com/nachfq/archer-markets (testnet).

On Wall Street, holders sell covered calls to earn on stocks they already own; the CBOE BXM index has tracked that strategy since 1986. On Robinhood Chain, Stonkhouse already offers covered calls and puts with an order book, and Archer Markets runs a testnet order book. Strike is different: an AI agent runs each vault, the contract enforces the vault's mandate, a rule-breaking agent is slashed and the bond goes to depositors.
