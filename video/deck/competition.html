Competition

Stonkhouse: stonkhouse.fun and its docs (order book, covered calls, puts). Archer Markets: github.com/nachfq/archer-markets (on-chain bid/ask book). Other-chain vaults: Ribbon/Aevo, Thetanuts docs. Tilt: tiltprotocol.com, NYC Open House 1st. AfterHours: its HackQuest entry in this buildathon. Detail: README "Competition".

Stonkhouse is live on mainnet and is the one to respect: an order book where writers and traders pick strikes. Archer Markets is a testnet order book. Vaults on other chains have an operator choose strikes and sell by auction. Tilt Protocol, which won the NYC online buildathon, is the closest agent product: an AI manager runs tokenized-stock vaults with RFQ pricing, but it sells no options and describes no bond that pays depositors when the agent breaks a rule. AfterHours, also in this buildathon, prices weekend puts on stock tokens with a model but has no agents, no mandate and uses tUSD. Strike is the only one where a bonded AI agent proposes, the contract checks the mandate and prices against the oracle, and a rule-breaking agent pays depositors.
